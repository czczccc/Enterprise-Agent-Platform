# Development Guide

## Development Philosophy

This project follows enterprise AI engineering principles.

Do not start from UI.

Start from:

1. Business workflow
2. Data sources
3. Tools
4. Agent reasoning
5. Execution flow

## Development Order

1. Documentation
2. Architecture
3. Minimal Agent
4. Tools
5. Workflow
6. Knowledge
7. Production features

## Git Workflow

Use small commits.

Each task should correspond to one feature.

## Agent Design

Every Agent should answer:

- What problem does it solve?
- What tools can it use?
- What data does it need?
- What actions can it execute?
- What requires human approval?
